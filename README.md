# PedeAi

Projeto estático de cardápio virtual com painel administrativo local e envio de pedidos pelo WhatsApp.

## Como usar

1. Abra `admin.html` para configurar a loja, categorias e itens.
2. Abra `index.html` para ver o cardápio público no mesmo navegador.
3. No painel, use `Baixar cardápio.html` para gerar uma versão estática com os dados atuais.

Os dados ficam salvos no navegador por `localStorage`. Use o backup JSON antes de trocar de computador ou limpar os dados do navegador.
